TEAM PHOTOS
===========

The About page looks for these files. Until one exists, that slot shows a
monogram instead — the layout never breaks.

  founder.jpg     portrait, 4:5 ratio (e.g. 800 x 1000)
  advisor-1.jpg   square, 240 x 240 or larger
  advisor-2.jpg
  advisor-3.jpg
  lead-1.jpg
  lead-2.jpg
  lead-3.jpg

Shoot or crop them consistently — same background treatment, same crop
distance, eyes on roughly the same line. Six headshots taken in six different
places is the single fastest way to make a team page look assembled rather
than real. If you only have LinkedIn photos of varying quality, a uniform
monogram set looks better than a mismatched photo set.
